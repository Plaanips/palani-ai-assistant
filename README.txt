MY AI ASSISTANT - FREE ANDROID INSTALLABLE WEB APP

Files: index.html, manifest.webmanifest, icon.svg, sw.js.

EASIEST FREE INSTALL (GitHub Pages):
1. Create a free GitHub account at github.com if you do not have one.
2. Create a new PUBLIC repository called my-ai-assistant. Do not put personal information or API keys in it.
3. Upload the four app files (not this README unless desired) to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, main, / (root), then Save.
5. Wait for GitHub Pages to show your HTTPS site URL. Open it in Chrome on Android.
6. Chrome menu > Add to Home screen > Install (or Add). The label may vary.
7. In the app, Settings > Get an API key at Google AI Studio. Sign in and create a key on a free eligible project. Do not enable billing. Paste the key into app Settings and save.
8. Chat! Tasks, projects and memory work without an API key.

IMPORTANT LIMITATIONS:
- Free Gemini API access and quotas depend on Google's current pricing, region and eligibility. Google may change them. Do not enable paid billing if you require £0 cost.
- This version is a local-first personal organiser with AI chat, not an autonomous agent. Chat does NOT directly create tasks/projects/memories. Use their tabs.
- Data is saved in localStorage on this browser and device, not synchronised. Export a JSON backup regularly.
- The Gemini API key is saved in browser localStorage, which is not a secure vault. Never put it in GitHub files or share your device/browser profile with untrusted people.
- AI prompts and saved memories, tasks and project context are transmitted to Google's Gemini API when you send a message. Do not enter identifiable care-home resident data, passwords or sensitive records.
- Service worker supports offline opening after the first successful visit; AI responses require internet.
- Voice recognition depends on Android browser support. Android keyboard dictation is a fallback.
- For stronger security and account sync, a future version should use a server-side API proxy and authentication; free hosting quotas may apply.
